# music/

Music tracks go here. Each **subfolder** becomes its own tunable station —
e.g. `music/Ambient/` and `music/Combat/` would be two separate stations
you can tune between. A track placed loose at the root of `music/` (no
subfolder) falls into a shared "General" station instead of being invisible.

Supported formats: `.mp3`, `.ogg`, `.oga`, `.flac`, `.wav`, `.m4a`, `.mp4`,
`.aac`.

This folder is never committed to git (large personal binaries) — only
this README and `.gitkeep` are tracked.
